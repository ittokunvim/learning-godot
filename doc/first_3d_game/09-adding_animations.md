# キャラクターのアニメーション

> 参考：https://docs.godotengine.org/ja/4.x/getting_started/first_3d_game/09.adding_animations.html

最後のレッスンではGodotに内蔵されたアニメーションツールを使って、キャラクターを浮かせたり羽ばたかせたりします。
エディターでアニメーションをデザインし、プログラムのコーディングを行ってゲームを生き生きしたものにします。

まずはアニメーションエディターの使い方から始めます。

## アニメーションエディターを使う

Godotエンジンのエディタには、アニメーションを作成するためのツールが付属しています。
さらにGodotエンジンのエディタでコードを書いて、実行時にアニメーションを再生したり制御したりすることができます。

Playerノードを選択し、AnimationPlayerノードを追加します。
するとしたパネルにアニメーションドックが表示されます。

それではアニメーションを作ってみましょう。
アニメーション、新規をクリックします。
アニメーション名は`float`とします。
アニメーションを作成すると、タイムラインに秒単位の時間が表示されます。

ゲーム開始時に自動的にアニメーションの再生が開始されるようにします。
またアニメーションがループ再生するようにします。

これを行うにはアニメーションツールバーの自動再生ボタンとアニメーションループの矢印をクリックします。

またピンアイコンをクリックするとエディタを固定することが可能です。
これによりビューポートをクリックしてノードの選択を解除した時に、折り畳まれることがなくなります。

アニメーションの長さを`1.2`秒に設定します。

## 浮遊アニメーション

アニメーションプレイヤーノードを使用すると、必要な数だけノード状のほとんどのプロパティをアニメーション化できます。
インスペクタのプロパティの鍵アイコンがあります。
これをクリックすると対応するプロパティの時間と値のペアであるキーフレームを作成することができます。
キーフレームはタイムライン状のタイムカーソルがアル場所に挿入されます。

最初のキーを挿入してみましょう。
ここではCharacterノードの位置と回転の両方をアニメーションさせます。

Characterを選択し、インスペクタのTransformセクションを展開し、PositionとRotationの横にある鍵アイコンをクリックします。

ここではRESETトラックとして作成します。
作成したらエディタに2つのトラックが表示され、それぞれのキーフレームを表す菱形のアイコンが表示されます。

菱形アイコンをドラッグすると時間軸の中を移動させることができます。

`position`を`0.3`秒、`rotation`を`0.1`秒に合わせます。
インスペクタでPositionプロパティのY軸を`0.65`メートル、RotationプロパティのX軸を`8`度に設定します。

`position, rotation`に新しくキーを挿入します。
`position`を`0.7`秒、`rotation`を`0.5`秒に合わせます。
インスペクタでPositionプロパティのY軸を`0.35`メートル、RotationプロパティのX軸を`0.9`度に設定します。

最後に2つのアニメーションに`1.2`秒のところにキーを挿入します。

> アニメーションの原理についてはこのチュートリアルでは取り扱いません。
> ただすべての動作のタイミングとスペーシングを均等にするわけではありません。
> アニメーターはアニメーションの2つの基本原則であるタイミングとスペーシングを使います。
> キャラクターを生き生きさせるには、オフセット（前の位置からどれくらいキャラクターをずらしたか）と
> コントラスト（どれくらい違いがあるか）をキャラクターの動きに設定することが必要です。

再生ボタンか`Shift+D`でプレビューできます。

エンジンがキーフレーム間を補完して連続したアニメーションを生成しているのがわかります。
しかし現時点では非常に機械的な動きです。
これはデフォルトの補完が直線的で、現実世界の生き物の動きとは異なり、キーフレーム間の動作が一定だからです。

イージングカーブ（モーションカーブ）を使い、キーフレーム間の遷移をコントロールすることができます。

タイムライン状の最初の2つのキー周辺をドラッグし、ボックス選択します。
ボックス選択をすると同時にプロパティの値を編集することが可能です。

Easingプロパティの線をクリックし、ドラッグして左方向に動かします。
これによりイーズアウト、つまり最初は早く移行し、タイムカーソルが次のキーフレームに近づくにつれて遅くなるようにします。

一度アニメーションを再生してみましょう。
前より少し弾力感があるように感じるはずです。

では回転(rotation_degrees)トラックにも同じようにイーズアウトを適用します。

次に後ろ2つのキーフレームは逆にイーズインしてみてください。

> アニメーションはフレームごとにアニメーションノードのプロパティを更新し、初期値を上書きします。
> Playerノードを直接アニメーションさせると、コードを使って移動や回転を行うことができなくなります。
> そこでPivotノードが役立ちます。
> Characterをアニメーションしていても、Pivotを移動回転させて、アニメーションしているキャラクターの移動や回転をスクリプト内で行うことができるのです。

もしクリーチャーが床に近いときはPivotを上に動かして高さを調整します。

### コードからアニメーションを制御する

コーディングによって、プレイヤーの入力に応じてアニメーションの再生を制御することができます。
キャラクターが動いている時のアニメーションの速度を変えてみましょう。

`player.gd`を開いて以下のコードを記述します。

```godotengine
func _physics_process(delta):
	#...
	if direction != Vector3.ZERO:
		#...
		$AnimationPlayer.speed_scale = 4
	else:
		$AnimationPlayer.speed_scale = 1
```

このコードではプレイヤーを動かした時に、再生速度を4倍にしています。

先ほどPivotノードは親ノードのアニメーションに移動や回転などの変化を追加すると述べました。
以下のコードではキャラクターがジャンプした時に弧を描かせることができます。

```godotengine
func _physics_process(delta):
	#...
	$Pivot.rotation.x = PI / 6 * velocity.y / jump_impulse
```

## モブをアニメーションさせる

Godotのアニメーションにはもう1つの便利な機能があります。
同じようなノード構造があれば、アニメーションを別のシーンにコピーできるのです。

例えば、MobシーンとPlayerシーンにはPivotとCharacterノードを持っているので、アニメーションを再利用することができます。

Playerシーンを開き、AnimationPlayerノードを選択し、アニメーションの管理をクリックします。
`float`アニメーションの横にあるコピーボタンをクリックします。

次にMobシーンを開き、AnimationPlayerを子ノードに追加します。
アニメーションの管理をクリックし、新しいライブラリを選択します。
そして貼り付けアイコンをクリックするとコピーできます。

次にアニメーションエディターで、自動再生ボタンとアニメーションループをオンにします。
これですべてのモンスターにアニメーションを再生することができました。

モブの`random_speed`に基づいて、アニメーションの再生速度を変更します。
`mob.gd`を開き、以下のコードを記述します。

```godotengine
func initialize(start_position, player_position):
	#...
	$AnimationPlayer.speed_scale = random_speed / min_speed
```

これで初めての完璧な3Dゲームのコーディングが完了しました！
