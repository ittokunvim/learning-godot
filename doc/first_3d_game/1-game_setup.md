# ゲームエリアの設定

> 参考：https://docs.godotengine.org/ja/4.x/getting_started/first_3d_game/01.game_setup.html

このパートではゲームエリアを設定します。
早速スタートアセットをインポートしてゲームシーンを設定しましょう。

このチュートリアルで使用するアセットは以下のURLから入手できます。

https://github.com/godotengine/godot-docs-project-starters/releases/download/latest-4.x/3d_squash_the_creeps_starter.zip

ダウンロードしたらZIPを解凍して、保存したい場所に移動します。
その後、Godotプロジェクトマネージャを開き、インポートを選択し、先ほどダウンロードしたアセットの中の`project.godot`を選択します。

## プレイ可能エリアの設定

プレーンなNodeをルートとしてMainという名前のメインシーンを作成します。

まず、キャラクターの落下を防ぐための床を追加します。
床、壁ー天井のような静的なコライダーを作成するには、StaticBody3Dノードが最適です。
これらは衝突判定を定愚するためにCollisionShape3Dという子ノードが必要です。
Mainノードを選択し、StaticBody3Dノードを追加し、StaticBody3DノードにCollisionShape3Dを子ノードとして追加します。
そしてStaticBody3Dの名前をGroundとします。

ツリーは以下の通りです。

- Main
    - Ground
        - CollisionShape3D

CollisionShape3Dに警告が出るのは、まだCollisionShape3Dの形を定義していないからです。
形状を定義するには、シーンドックのCollisionShape3Dを選択し、インスペクタードックの`Shape`プロパティを選択します。
そこから新規BoxShape3Dを選択して形状を作成します。

ボックスの形状は平らな地面や壁に最適です。
その厚さによって動きの速い物体でも確実にブロックできます。

追加したボックスのワイヤーフレームが、ビューポートに3つのオレンジ色の点で表示されます。
これらは形状の大きさをインタラクティブに編集可能です。
またインスペクタ上で正確に設定することもできます。
BoxShape3Dを選択し、Size項目で`x: 60, y: 2, z: 60`と指定します。

衝突形状は目に見えないため床を追加する必要があります。
GroundノードにMeshInstance3Dを子ノードとして追加します。

インスペクタからMesh項目を選択し、新規BoxMeshを選択し、Sizeを`x: 60, y: 2, z: 60`にします。

ビューポートにはメッシュのプレビューが表示されるはずです。

床のグリッドが見えるように地面を動かします。
これを行うためにグリッドスナップ機能を使用します。
3Dエディタでは2つの方法でグリッドスナップを有効にできます。
1つはUse Snapを選択する方法で、2つはノードを選択し、ギズモのハンドルをドラッグした後、選択したノードを保持したまま`Cmd`キーを押す方法です。

Groundを1メートル下に移動させます。
ギズモを操作している間ビューポートの左下隅に表示されるラベルは、ノードをどれくらい並行移動したかを示しています。

最終的にGroundのY座標の値が`-1`になるように変更しましょう。

シーンがグレー色にならないように、ディレクショナルライトを追加します。
MainノードにDirectionalLight3Dを子ノードとして追加します。

Directional3Dに移動し、地面が照らされるようにX軸を中心に回転させます。
またインスペクタでShadowプロパティをオンにしておきます。
