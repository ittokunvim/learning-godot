# GDScriptを使ったコーディング

> 参考：https://docs.godotengine.org/ja/4.x/getting_started/introduction/learn_to_code_with_gdscript.html

Godotではプログラミング言語としてGDScriptとC#が使えます。

プログラミングが簡単なのはGDScriptなのでおすすめです。
C#を使い慣れているならC#のほうが良いでしょう。

GDScriptはGodot固有の言語ですが、他のプログラミング言語でも役に立ちます。

プログラマーが複数の言語を学び、使用するのは全くの普通のことです。
プログラミング言語には相違点より類似点の方が多いため、1つ取得していれば、別の言語でも使えます。

## GDScriptアプリを使ってブラウザで学習する

GDScriptの学習に、アプリ「0から学ぶGDScript」を使用できます。
これは完全な初心者向けコースで、ブラウザ上で直接実行できるインタラクティブな練習項目を備えています。
