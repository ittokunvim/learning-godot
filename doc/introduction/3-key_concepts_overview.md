# Godotのキーコンセプトの概要

> 参考：https://docs.godotengine.org/ja/4.x/getting_started/introduction/key_concepts_overview.html

全てのゲームエンジンには、アプリケーションを作成する為の抽象的な概念を軸に構成されています。
Godotでは、ゲームはシーンの中にグループ化されているノードのツリーで表されます。
これらのノード同士は繋ぐことができ、シグナルを使ってお互いに交信できます。

ここでは4つのコンセプトを見ていきながら、エンジンの動き方の感覚を掴んでいきましょう。

## シーン

Godotでは、ゲームを再利用可能なシーンに分割します。
シーンは、キャラクター、武器、メニュー、建物、レベル全体などのあらゆるものになります。
Godotのシーンはフレキシブルであり、他のゲームエンジでいうプレハブとシーン両方の役割を果たします。

シーンを入れ子にすることもでき、キャラクターにレベルを追加するとして、
レベルシーンをキャラクターシーンの子として追加できます。

## ノード

シーンは1つ以上のノードで構成されています。
ノードはゲームを構成する最小ブロックで、ツリー型に配置することができます。

ノードとシーンはエディタでは同じように見えるので注意が必要です。
ノードツリーはシーンとして保存されると、エディタからは内部構造が隠れます。

Godotエンジンでは広範囲のタイプの基本ノードを提供しており、組み合わせたり、拡張することもできます。
2D, 3D, UIなど、大抵のものはノードで表現できます。

## シーンツリー

ゲームシーンは、1つのシーンツリーに収められます。
シーンがノードのツリーでできているように、シーンツリーもノードのツリーでできています。
シーンはゲームの中で、キャラクター・武器・ドア・UIなどで考えるとわかりやすいです。

## シグナル

ノードは何かイベントが発生するとシグナルを発信します。
この仕組みはノード同士がコードで密結合することなく、やりとりすることを可能にし、
シーンの構築に柔軟さをもたらします。

例えば、ボタンが押された時にシグナルが発信されます。
このシグナルに接続することで、イベントとしてゲームの開始や、メニューを開く処理を
実行することができます。

他の組み込み済みのシグナルでは2つのオブジェクトの接触や、
キャラクターやモンスターが一定のエリアに侵入したことを通知することもできます。
また独自のシグナルを自分自身で定義することもできます。

## まとめ

ノード、シーン、シーンツリー、シグナルはGodotにおいて4つの中核となる概念で、常に操作することになります。

ノードはゲームを構成する最小ブロックです。
それらを組み合わせてシーンを作り、シーンツリーの中に入れ子にしていきます。
シーンツリーの別の枝葉のノードにイベントとしてシグナルを使うことができます。
