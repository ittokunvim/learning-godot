# Playerシーンの作成

> 参考：https://docs.godotengine.org/ja/4.x/getting_started/first_2d_game/02.player_scene.html

プロジェクト設定が完了したので、操作できるキャラクターを作成します。

最初のシーンでは、`Player`オブジェクトを定義します。
Playerシーンを独立して作成する利点は、ゲームの他の部分を作成する前でもテストができるところです。

## ノード編成

初めに、プレイヤーオブジェクトのルートノードを選択する必要があります。
原則として、シーンのルートノードはオブジェクトに望まれる機能を反映する必要があります。
シーンタブで、その他ノード、Area2Dノードを追加します。

Godotには、2Dキャラクター向けに特別に設計された「CharacterBody2D」ノードが用意されております。
実際のプロジェクトでは、プレイヤーや敵キャラクターには「CharacterBody2D」の方が適している場合が多いでしょう。
ただしここでは、より幅広いノードやユースケースに適用できる中核的な概念に焦点を当てています。

Area2Dを選択すると警告が出ます。
これはArea2Dノードが衝突や重なりを検出するために形状を必要とすることを示しています。
プレイヤーのビジュアルを最初に設定するため、警告は一旦無視します。
ビジュアルが準備できたら後でスプライトの外観に基づいて設定を行います。

Area2Dを使用すると、プレイヤーに重なったり衝突したりするオブジェクトを検出できます。
ノードの名前を`Player`すると、ノードに機能を追加できます。

`Player`ノードに子を追加する前に、誤操作で移動やサイズを変更しないようにします。
ノードを選択し、鍵アイコンの右側にあるアイコンをクリックします。

ここまでできたらシーンを`player.tscn`で保存します。

## スプライトアニメーション

プレイヤーノードをクリックして`AnimatedSprite2D`ノードを子として追加します。
`AnimatedSprite2D`は、プレイヤーの外見とアニメーションを処理します。
警告が出てると思いますが、これは表示可能なアニメーションのリストである`SpriteFrames`リソースがないから出ています。
作成するにはインスペクタの`animation`タブ内の`Sprite Frames`プロパティの新規SpriteFramesをクリックします。

左側にアニメーションリストがあり、`default`から`walk`に名前を変更します。
次に`Add Animation`をクリックして、`up`という名前の2番目のアニメーションを作成します。

プレイヤー画像は`art`フォルダの中にあります。
2つの画像を対応するアニメーションパネルのアニメーションフレーム側にドラッグします。

プレイヤーの画像はゲームウィンドウに対して大きすぎるため縮小する必要があります。
`AnimatedSprite2D`の`scale`プロパティを`0.5`にします。

最後に`CollisionShape2D`をPlayerの子として追加します。
これによりプレイヤーのヒットボックス、つまり衝突領域の境界が決まります。
今回の場合`CapsuleShape2D`ノードが最適なので、インスペクタのShapeから新規CapsuleShape2Dを選択します。

これが完了すると、Area2Dノードの警告が消えるはずです。
変更したら必ずシーンを保存します。

次のパートでは、動かしたりアニメーションさせるためのスクリプトをPlayerノードに追加します。
そしてプレイヤーに何が当たったかわかるように、衝突判定を設定します。
