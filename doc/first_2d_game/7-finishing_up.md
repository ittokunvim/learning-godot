# 仕上げ

> 参考：https://docs.godotengine.org/ja/4.x/getting_started/first_2d_game/07.finishing-up.html

ここまででゲームの全ての機能は完成しました。
以下はゲーム体験を向上させるためにもう少し彩りを加えるものです。

## 背景

デフォルトのグレー背景は味気がないので、色を変更してみましょう。
1つの方法はColorRectノードを使用することです。
他のノードの後ろに描画されるように、メインの下の最初のノードにします。
ColorRectには、Colorというプロパティのみがあります。
好きな色を選択し、レイアウト、アンカー、Rect全面を選択します。

背景画像がある場合は、TextureRectノードを使用します。

## 効果音

サウンドと音楽は、ゲーム体験に魅力を与える最も効果的な方法の1つです。
アセットフォルダにはBGM用の`House In a Forest Loop.ogg`、ゲームオーバー用の`gameover.wav`というファイルがあります。

2つのAudioStreamPlayerノードをメインに追加します。名前は`Music, DeathSound`とします。
各ファイルに`Stream`プロパティでオーディオファイルを読み込みます。

オーディオはデフォルトで`loop`が無効状態です。
ループするにはユニーク化を選択し、`Loop`にチェックします。

では以下のコードを各関数に追加します。

```godotengine
func game_over():
	# ...
	$Music.stop()
	$DeathSound.play()

func new_game():
	# ...
	$Music.play()
```

## キーボードショートカット

このゲームはキーボードでプレイするので、キーボードのキーを押してゲームを始められると便利です。
それにはButtonノードのShortcutプロパティを使えばできます。

前回のレッスンでプレイヤー移動のためにキーの設定をしました。
同様の入力アクションを使用すれば実装可能です。

プロジェクト、設定、インプットマップから`start_game`という入力アクションを作成し、Enterキーで追加します。

追加したいコントローラがあれば、今が良いタイミングです。

HUDシーンでStartButtonを選択し、Shortcutプロパティから新規Shortcutを作成し、Array\[InputEvent\](size 0)をクリックして要素を追加します。

新しいInputEventActionを作成し、`start_game`アクションを選択します。

ではゲームを実行してみて、エンターキーを押してゲームが始まったら成功です。

これでGodotで最初の2Dゲームが完成しました。

操作可能なキャラクター、ランダムに出現する敵、スコアのカウント、ゲームオーバーやリプレイの実装、UI、音楽など実装しました。

## ゲームを共有する

Godotをインストールせずにゲームを試したい場合は、ゲームがプレイかのうな各OS用にプロジェクトをエクスポートする必要があります。
手順は、[プロジェクトのエクスポート](https://docs.godotengine.org/ja/4.x/tutorials/export/exporting_projects.html#doc-exporting-projects)を参照ください。

プロジェクトをエクスポートした後、実行可能ファイルとPCKファイルをZIPファイルに圧縮し、
そのZIPファイルをファイル共有ウェブサイトにアップロードすることで共有することができます。
